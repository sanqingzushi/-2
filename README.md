# Atlas Market Watch｜全球投资监测台

这是一个面向个人投资研究的公开仪表盘，已先部署静态前端到 GitHub 仓库。它使用第三方 TradingView 嵌入图表展示主要指数与部分期货行情。

## 当前已实现
- 响应式中文界面，支持手机与电脑。
- 按美国指数、中国市场、港股/全球、期货/商品、基金风险分类筛选。
- 展示道指、标普500、纳指100、纳斯达克综合、罗素2000、VIX等图表。
- 展示 ETF 溢价警戒规则与个人观察清单。
- 每60秒更新页面的检查时间戳。

## 重要限制
**页面时间戳每分钟更新，不代表行情数据每分钟刷新。** TradingView组件由其自身控制更新频率，可能延迟；不同品种的数据权限与覆盖不同。

尚未接入结构化行情API，因此目前不会声称有真实的实时ETF溢价率、IOPV、场外基金申购限额、基金净值或自动买入信号。未验证的数据标为待核查。

## GitHub Pages 部署
1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 中选择 GitHub Actions（如果使用下面的 workflow）。
3. 等待 Actions 的 Pages 部署 workflow 成功。
4. 仓库为 `sanqingzushi/-2` 时，预期网址为 `https://sanqingzushi.github.io/-2/`；仅当 Pages 部署成功后该网址才可访问。

## 后续分钟级数据更新
需要 Cloudflare Workers + D1，以及有权用于自动采集和网页展示的行情数据接口。Workers 可以每分钟运行，但不能保证数据源每分钟产生新报价。ETF溢价只能使用同一时点、同币种的场内价格与可验证 IOPV计算；不能拿前一日基金NAV伪装成实时IOPV。场外申购限额应按官方公告/实际销售渠道更新，通常不需要每分钟轮询。

不要把任何 API Token、个人证券账户、现金余额或私密持仓信息提交到公开仓库。
