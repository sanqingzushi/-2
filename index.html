检查频率与数据边界

网页在打开时每60秒拉取快照；后台默认使用 GitHub Actions，调度目标5分钟，可能排队延迟或漏跑。每分钟 Cloudflare 调度只有完成部署并接入后才会显示启用。关闭手机网页不会停止已部署的后台任务。

公共行情源无可用性或时延保证，访问失败保留旧报价和原时间；返回相同报价时间不会冒充新数据。场外净值按小时核查，不从最小申购金额推断申购上限。接口未配置、失败、限流与预算暂缓会单独标记。

页面是研究工具。没有账户连接、自动下单或交易信号。第三方行情仅供核查，交易价格与基金可买性以实际交易渠道为准。
